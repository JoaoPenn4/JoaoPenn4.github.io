rclone VM Oracle

Aplicação de uso pessoal que faz backup automático e criptografado de um servidor pessoal para o Google Drive do próprio dono, usando o rclone. Não é oferecida a terceiros.

Política de Privacidade

Dados acessados: a aplicação usa apenas o escopo drive.file do Google Drive, ou seja, só enxerga os arquivos que ela mesma criou. Ela não lê, lista nem altera outros arquivos do Drive.

Uso: os arquivos enviados são backups do servidor do próprio usuário, criptografados antes do envio. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade ou treinamento de modelos.

Armazenamento: os tokens de acesso ficam somente no servidor do usuário. Os backups ficam no Google Drive do usuário e são apagados automaticamente após 30 dias.

Revogação: o acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Termos de Serviço

Uso pessoal, sem garantias. Não há usuários externos.
