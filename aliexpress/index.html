What it does

A personal affiliate tool that helps Brazilian users find products on AliExpress through an AI assistant. It searches products, shows prices in BRL with shipping to Brazil, and generates affiliate links that are tracked through my AliExpress Portals affiliate account.

AliExpress Affiliate API methods used

  • aliexpress.affiliate.product.query: product search
  • aliexpress.affiliate.productdetail.get: product details
  • aliexpress.affiliate.hotproduct.query: trending products
  • aliexpress.affiliate.category.get: category list
  • aliexpress.affiliate.featuredpromo.get and featuredpromo.products.get: promotions
  • aliexpress.affiliate.link.generate: affiliate link generation

How it works

The app runs as an MCP (Model Context Protocol) server. A user asks an AI assistant for a product, the server queries the Affiliate API (ship to: BR, currency: BRL, language: PT) and returns the results with affiliate links. The user completes any purchase on AliExpress itself.

Data

The app reads only public product and promotion data. It does not collect, store or share buyer personal data, and it does not process orders or payments. See the privacy policy.
